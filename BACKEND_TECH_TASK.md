## 1. Course Management Endpoints

### 1.1 Create Course

**Endpoint**: `POST /api/courses/create`

**Authentication**: Required (Admin only)

**Request Body**:
```json
{
  "title": "string (required)",
  "shortDescription": "string (required)",
  "longDescription": "string (optional)",
  "image": "string (optional)",
  "icon": "string (required, default: 'default')",
  "price": "number (required, > 0)",
  "duration": "number (optional, minutes)",
  "contentUrl": "string (required, video URL)",
  "featured": "boolean (optional, default: false)"
}
```

**Response**: `200 OK`
```json
{
  "id": "string",
  "title": "string",
  "shortDescription": "string",
  "longDescription": "string | null",
  "image": "string | null",
  "icon": "string",
  "price": 99.99,
  "duration": 60,
  "contentUrl": "string",
  "featured": false,
  "createdAt": "ISO8601 datetime",
  "updatedAt": "ISO8601 datetime",
  "createdBy": "string | null",
  "updatedBy": "string | null"
}
```

**Validation Rules**:
- `title`: Required, min 3 characters, max 200 characters
- `shortDescription`: Required, min 10 characters, max 500 characters
- `longDescription`: Optional, max 5000 characters
- `price`: Required, must be > 0
- `duration`: Optional, must be > 0 if provided
- `contentUrl`: Required, must be valid URL
- `icon`: Required, default to 'default' if not provided

**Error Responses**:
- `400 Bad Request`: Validation errors
- `401 Unauthorized`: Not authenticated
- `403 Forbidden`: Not admin user
- `500 Internal Server Error`: Server error

---

### 1.2 Update Course

**Endpoint**: `PUT /api/courses/{courseId}`

**Authentication**: Required (Admin only)

**Request Body**: Same as Create Course (all fields optional except validation rules apply)

**Response**: `200 OK` (Same as Create Course)

**Validation Rules**: Same as Create Course

**Error Responses**:
- `400 Bad Request`: Validation errors
- `401 Unauthorized`: Not authenticated
- `403 Forbidden`: Not admin user
- `404 Not Found`: Course not found
- `500 Internal Server Error`: Server error

---

### 1.3 Delete Course

**Endpoint**: `DELETE /api/courses/{courseId}`

**Authentication**: Required (Admin only)

**Response**: `204 No Content` (on success)

**Error Responses**:
- `401 Unauthorized`: Not authenticated
- `403 Forbidden`: Not admin user
- `404 Not Found`: Course not found
- `409 Conflict`: Course has active orders (cannot delete)
- `500 Internal Server Error`: Server error

**Business Logic**:
- Check if course has any orders before deletion
- If orders exist, return 409 Conflict with message
- Soft delete option: Mark as deleted instead of hard delete (recommended)

## 6. File Upload Endpoints

### 6.1 Upload Image

**Endpoint**: `POST /api/upload/image`

**Authentication**: Required (Admin only)

**Request**: `multipart/form-data`
- Field name: `file`
- Content-Type: `image/*` (jpeg, png, gif, webp)
- Max file size: 5MB

**Response**: `200 OK`
```json
{
  "url": "string (full URL to uploaded image)",
  "filename": "string",
  "size": "number (bytes)",
  "contentType": "string"
}
```

**Error Responses**:
- `400 Bad Request`: Invalid file type or size exceeded
- `413 Payload Too Large`: File too large
- `500 Internal Server Error`: Upload failed

**Storage Requirements**:
- Store files in cloud storage (S3, Cloudinary, etc.) or local storage
- Generate unique filenames to avoid conflicts
- Return full accessible URL

## 11. Error Handling

### 11.1 Standard Error Responses

**Format**:
```json
{
  "error": "Error Type",
  "message": "Human-readable error message",
  "code": "ERROR_CODE (optional)",
  "details": {} // Optional additional details
}
```

**HTTP Status Codes**:
- `200 OK`: Success
- `201 Created`: Resource created
- `204 No Content`: Success (delete)
- `400 Bad Request`: Validation error
- `401 Unauthorized`: Not authenticated
- `403 Forbidden`: Not authorized (not admin)
- `404 Not Found`: Resource not found
- `409 Conflict`: Business rule violation (e.g., cannot delete course with orders)
- `413 Payload Too Large`: File too large
- `500 Internal Server Error`: Server error
