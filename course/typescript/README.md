# TypeScript Course — Dart Developer Edition

A hands-on course for Dart/Flutter developers learning TypeScript by doing.
Every lesson has runnable tasks. You write them, you run them, you submit them for review.

---

## Setup

```bash
cd course/typescript
npm install
```

## Running a task

```bash
npx tsx 01_basic_types/task01.ts
```

## Rules

- Do tasks in order. Later lessons build on earlier ones.
- Run the task before submitting. If it doesn't compile, fix it first.
- When submitting: paste your code and say "verify lesson X task Y."
- You may ask questions about theory. You may not ask for solutions.
